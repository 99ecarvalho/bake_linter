# STYLE006 - Duplicate Inherit

**Severity:** warning

**Category:** style

**Enabled by Default:** Yes

---

## Description

Check for duplicate inherit class references

## Example of Bad Code

```bitbake
inherit cmake pkgconfig cmake
inherit setuptools3
```

## Why This Is Bad

Duplicate `inherit` entries are redundant and can confuse readers about ordering or intent. They also increase maintenance noise without changing behavior.

## How to Fix It

```bitbake
inherit cmake pkgconfig
inherit setuptools3
```

Keep each class inherited once. Remove duplicate class names within the same `inherit` line or across multiple lines.

## Inline Suppression

If you need to suppress this rule for a specific line, add a comment:
