# PKG001 - RDEPENDS on Development Package

**Severity:** error

**Category:** packaging

**Enabled by Default:** Yes

---

## Description

Detects -dev packages incorrectly in RDEPENDS


The check mirrors the `dev-deps` QA test in `insane.bbclass`: a runtime
dependency whose name ends in `-dev` is reported unless the depending
package is itself a development package (its name contains `-dev` or
`-staticdev`), a debug package, a packagegroup or an image, the recipe
inherits `kernel` or `module-base`, or `INSANE_SKIP` for that package
lists `dev-deps`. Version constraints such as `(>= 1.0)` are ignored.
