# DEPRECATED001 - Deprecated Override Syntax

**Severity:** warning

**Category:** deprecated

**Enabled by Default:** Yes

---

## Description

Detects the old underscore-based override syntax which has been deprecated in favor of colon-based syntax since the Honister (3.4) release of the Yocto Project.

## Example of Bad Code

```bitbake
# Old syntax with underscores (deprecated)
SRC_URI_append_arm = " file://arm-specific.patch"
RDEPENDS_${PN}_append = " extra-package"
COMPATIBLE_MACHINE_raspberrypi4 = "raspberrypi4"
```

## Why This Is Bad

The underscore syntax is **deprecated and will be removed** in future Yocto releases:
- **Future incompatibility**: Code using old syntax will break in newer Yocto versions
- **Harder to read**: Underscores are ambiguous - is `VAR_append_arm` an append to `VAR` for `arm` or a variable named `VAR_append_arm`?
- **Best practices**: The colon syntax is clearer and more maintainable
- **Tool support**: Newer tools expect colon syntax

## How to Fix It

Use the modern colon-based override syntax:

```bitbake
# New syntax with colons (correct)
SRC_URI:append:arm = " file://arm-specific.patch"
RDEPENDS:${PN}:append = " extra-package"
COMPATIBLE_MACHINE:raspberrypi4 = "raspberrypi4"
```

### Conversion Rules

| Old Syntax | New Syntax |
|------------|------------|
| `VAR_append` | `VAR:append` |
| `VAR_prepend` | `VAR:prepend` |
| `VAR_remove` | `VAR:remove` |
| `VAR_machine` | `VAR:machine` |
| `VAR_distro` | `VAR:distro` |
| `VAR_append_machine` | `VAR:append:machine` |

### Key Points
- Replace `_append`, `_prepend`, `_remove` with `:append`, `:prepend`, `:remove`
- Machine and distro overrides become `:machine`, `:distro`
- Multiple overrides are chained with colons: `:append:machine`

## Inline Suppression

If you're maintaining legacy code or have a specific reason to keep old syntax temporarily:

```bitbake
# nolint: DEPRECATED001
SRC_URI_append = " file://old-syntax.patch"
```

**Note:** This should only be used as a temporary measure during migration.
