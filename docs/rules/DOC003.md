# DOC003 - Truncated DESCRIPTION

**Severity:** info

**Category:** documentation

**Enabled by Default:** Yes

---

## Description

Detects DESCRIPTION that appears truncated

## Example of Bad Code

```bitbake
RECIPE = "myapp"
DESCRIPTION = "A comprehensive application that provides many feat"
# Description looks cut off
```

## Why This Is Bad

Truncated DESCRIPTION fields are incomplete documentation. Users and package managers cannot understand the recipe's purpose. Truncation often indicates copy-paste errors or line length limits that have cut off important information, reducing package quality and discoverability.

## How to Fix It

```bitbake
RECIPE = "myapp"
DESCRIPTION = "A comprehensive application that provides many features for system administration and monitoring"
```

Write complete, descriptive DESCRIPTION entries that clearly explain the recipe's purpose and functionality. Aim for 50-150 characters for clarity.
