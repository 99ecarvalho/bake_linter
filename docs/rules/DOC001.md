# DOC001 - Identical SUMMARY and DESCRIPTION

**Severity:** warning

**Category:** documentation

**Enabled by Default:** Yes

---

## Description

Detects when SUMMARY and DESCRIPTION have the same content

## Example of Bad Code

```bitbake
SUMMARY = "A build tool"
DESCRIPTION = "A build tool"
```

## Why This Is Bad

`SUMMARY` and `DESCRIPTION` should serve different purposes: SUMMARY is a one-liner, DESCRIPTION provides details. Identical text wastes documentation space.

## How to Fix It

```bitbake
SUMMARY = "A build tool"
DESCRIPTION = "A fast, portable build tool for systems. Supports incremental builds, multiple output formats, and remote caching."
```

Write distinct documentation: SUMMARY as a short phrase, DESCRIPTION as a fuller explanation of features and use cases.
