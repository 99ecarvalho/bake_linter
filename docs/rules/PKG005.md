# PKG005 - RDEPENDS Package Existence

**Severity:** error

**Category:** packaging

**Enabled by Default:** Yes

---

## Description

Ensures packages referenced in RDEPENDS:pkg are in PACKAGES

## Example of Bad Code

```bitbake
PACKAGES = "${PN} ${PN}-dbg"

RDEPENDS:${PN}-tools = "${PN}-helpers"  # ${PN}-helpers not defined in PACKAGES
```

## Why This Is Bad

If a package listed in `RDEPENDS:pkg` is not produced (absent from `PACKAGES`), the build emits QA errors and the dependency is unsatisfied at runtime. This leads to broken installs and missing functionality.

## How to Fix It

```bitbake
PACKAGES = "${PN} ${PN}-dbg ${PN}-helpers ${PN}-tools"

FILES:${PN}-helpers = "${libdir}/myapp/helpers/*"
RDEPENDS:${PN}-tools = "${PN}-helpers"
```

Define every package referenced in `RDEPENDS` inside `PACKAGES`, and ensure `FILES:pkg` selects the installed paths for that package. Adjust or drop the dependency if the package is not needed.
