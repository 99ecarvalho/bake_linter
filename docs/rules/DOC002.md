# DOC002 - Missing SUMMARY

**Severity:** info

**Category:** documentation

**Enabled by Default:** Yes

---

## Description

Detects recipe files without SUMMARY

## Example of Bad Code

```bitbake
PV = "1.0"
LICENSE = "MIT"
# Missing SUMMARY
```

## Why This Is Bad

Without `SUMMARY`, package metadata is incomplete. Users cannot see what the package does without reading the recipe.

## How to Fix It

```bitbake
SUMMARY = "HTTP library for system integration"
DESCRIPTION = "A lightweight HTTP client library with TLS support."
PV = "1.0"
LICENSE = "MIT"
```

Always provide a `SUMMARY` (ideally a single line, under 80 chars) describing what the package is.
