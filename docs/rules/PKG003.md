# PKG003 - Wildcard bbappend Overreach

**Severity:** warning

**Category:** packaging

**Enabled by Default:** Yes

---

## Description

Detects wildcard .bbappend with version-specific changes

## Example of Bad Code

```bitbake
# Wildcard bbappend with version-specific patch
# file: recipes-foo/foo/foo_%.bbappend
SRC_URI:append = " file://fix-1.2.3-upstream.patch"
```

## Why This Is Bad

Wildcard bbappends (`*_%.bbappend`) apply to all versions of a recipe. Adding version-specific content there can break unrelated versions or introduce subtle regressions when the recipe is upgraded.

## How to Fix It

```bitbake
# Use a version-specific bbappend when content depends on a particular version
# file: recipes-foo/foo/foo_1.2.3.bbappend
SRC_URI:append = " file://fix-1.2.3-upstream.patch"

# Alternatively, move truly generic changes into the wildcard bbappend and
# keep version-bound changes in versioned files.
```

Place changes that only apply to specific versions in `foo_<version>.bbappend`. Keep wildcard bbappends limited to content that safely applies across all maintained versions.
